metadata:

Write the PR body in the voice that [wait-what](../wait-what/SKILL.md) asks for, in no more than two paragraphs. Cover:

- what the change is
- why we're doing it
- how it works

When the diff is small enough to explain in a few sentences, write only those sentences.
