### Triage

**You own each verdict. The tracker gets what the evidence supports.**

1. Run the **triage** skill over every issue or PR in scope through its verify and grill steps. Draft each item's label and its notes or brief, and hold the posting step.
2. Label per the Labelling a ticket trigger.
3. Meet every item in **Verify** over the drafts.
4. Give the user one table of the verified drafts as the triage skill's direction point, then post each item as the user directs. A draft the user's direction changes gets its Fresh check before it posts.

**Reply:** one row per item: its label, the evidence behind it, and what you posted.
