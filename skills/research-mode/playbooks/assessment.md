### Assessment

**You own the judgment. Give your real one.**

1. Write the question as a decision: the options, and what the user does differently under each. For "are we sure", the option pair is the claim under doubt and its negation.
2. List the premises each option rests on, and trace each per **Evidence**.
3. Settle each fork that running something answers, per the Empirical fork trigger.
4. Build a tradeoffs table: one row per option, with a column for each criterion the user named, plus cost and risk.
5. Recommend one option with its reasons. When the question's premise fails, say so and answer the question it should have been.
6. Meet every item in **Verify**.

**Reply:** the recommendation first, then the tradeoffs table, each premise with its evidence, and what finding would change the recommendation.
