### Investigation

**You own the answer. Plan, route, write.**

1. Route the question per the Routing a question trigger.
2. Produce each routed skill's output as that skill defines it. A trace's output has these sections, less any that do not apply: Overview, Key Concepts, How It Works, Where Things Live, Gotchas.
3. When the question turns into a decision between options, continue in `playbooks/assessment.md`.
4. Meet every item in **Verify**.

**Reply:** the investigation output. For `research`, the file's path and the findings that answer the question.
