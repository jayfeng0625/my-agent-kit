# Triage roles

Each triage role is a tracker status with the same name.

| Role | Status |
| --- | --- |
| needs-triage | `Backlog` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

Work in flight uses `In Progress`, a verified change waiting on a person uses `Ready For Human Review`, and landed work is `Done`.
